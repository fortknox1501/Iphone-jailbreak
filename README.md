# Jailbreak Install Page

1. Sign `h3lixJailbreak.ipa` with Sideloadly using your Apple ID
2. Replace the IPA file in this repo with the signed version
3. Visit this GitHub Pages URL in Safari on the iPhone
4. Tap the banner to install
5. Tap Step 2 (or go to Settings manually) to trust the profile
6. Re-sign and re-upload every 7 days (free Apple ID limit)
